# Number Guessing Game

## Description

This is a Java-based Number Guessing Game. The program generates a random number between 1 and 100, and the user has to guess the correct number within a limited number of attempts.

## Features

* Random number generation (1–100)
* User input using Scanner
* Feedback for each guess:

  * Too High
  * Too Low
  * Correct Guess
* Limited number of attempts
* Multiple rounds
* Score tracking

## Technologies Used

* Java
* Scanner Class
* Random Class

## How to Run

1. Compile the program:
   javac numbergame.java

2. Run the program:
   java numbergame
